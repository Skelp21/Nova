# Nota — музыкальный агрегатор для Windows, Android и iPhone

> **Телефоны и аккаунт с плейлистами** — см. [MOBILE.md](MOBILE.md).

Десктопный плеер по образцу Dotify: **YouTube Music, SoundCloud, ВКонтакте и Яндекс Музыка** в одном окне.
Стек как у оригинала: **Tauri 2 (Rust) + React + TypeScript**. Без своего сервера — всё хранится на компьютере.

## Что умеет

| Раздел | Возможности |
|---|---|
| Поиск | Сразу во всех сервисах или по одному, вкладки по источникам, подборки жанров |
| Плеер | Очередь (вверх/вниз/удалить), перемешивание, повтор (всё/один), скорость 0.5–2× без смены тона, перемотка с буфером |
| «Моя волна» | Бесконечное радио по лайкам и истории или по конкретному треку, дизлайк = пропуск и исключение из волны |
| Библиотека | «Мне нравится», плейлисты (создать, переименовать, удалить, порядок), история (500), фильтр по коллекции |
| Импорт | Плейлисты и альбомы Spotify по ссылке (с подбором треков в выбранном сервисе), «Моя музыка» ВК, «Мне нравится» Яндекса |
| Офлайн | Скачивание треков и целых плейлистов; HLS ВКонтакте расшифровывается (AES-128) и собирается в один mp3 |
| Текст песен | Синхронный текст с подсветкой строки и переходом по клику (lrclib.net), обычный текст как запасной вариант |
| Звук | 10-полосный эквалайзер + предусиление, 10 пресетов, свои пресеты |
| Вид | 5 тем, акцентный цвет (в т. ч. свой), фон из размытой обложки, компактные строки, своя рамка окна |
| Интеграции | Мини-плеер поверх окон, медиаклавиши и панель мультимедиа Windows, Discord Rich Presence |
| Горячие клавиши | Пробел, Ctrl+←/→, ←/→, ↑/↓, M, L, Ctrl+F |

Соцчасть Dotify (аккаунты, друзья, чат, комнаты), магазин, аукцион и инвентарь в эту версию не входят: им нужен собственный сервер.

## Сборка

**Проще всего:** дважды щёлкните `СОБРАТЬ EXE.bat`. Скрипт сам поставит Node.js, Rust и C++ Build Tools через winget (если их нет), соберёт проект и откроет папку `output` с `Nota.exe` и установщиками.

Вручную:

Нужно один раз установить:
1. **Node.js 20+** — https://nodejs.org
2. **Rust** — https://rustup.rs (stable, MSVC)
3. **Visual Studio Build Tools** с компонентом «Разработка классических приложений на C++»
4. WebView2 уже есть в Windows 10/11

Затем в папке проекта:

```bash
npm install
npm run tauri dev      # запуск в режиме разработки
npm run tauri build    # установщик: src-tauri/target/release/bundle/msi/Nota_0.1.0_x64_en-US.msi (и NSIS .exe)
```

Первая сборка Rust занимает 3–6 минут, дальше быстро.

## Как это устроено

```
src-tauri/src/
  providers/youtube.rs     поиск и радио через InnerTube (WEB_REMIX), поток через клиент ANDROID_VR, запасной путь — yt-dlp
  providers/soundcloud.rs  api-v2, client_id берётся с сайта и обновляется сам
  providers/vk.rs          API audio.* через клиент Kate Mobile, вход через окно OAuth ВКонтакте
  providers/yandex.rs      API мобильного клиента, подпись ссылки на mp3, вход через окно OAuth Яндекса
  providers/spotify.rs     чтение публичного плейлиста со страницы embed (без входа)
  providers/lyrics.rs      lrclib.net
  proxy.rs                 локальный прокси 127.0.0.1: CORS для эквалайзера, нужные заголовки, перепись HLS, файлы с диска
  downloads.rs             скачивание, HLS + AES-128 + разбор MPEG-TS
  discord.rs, accounts.rs  Rich Presence и токены (accounts.json в папке конфигурации)
src/
  lib/audio.ts             один <audio> → Web Audio (предусиление + 10 biquad-фильтров), hls.js
  store/player.ts          очередь, волна, переключение треков
  store/library.ts         лайки, плейлисты, история, загрузки → library.json
  pages/, components/      интерфейс; miniplayer.html + src/mini.tsx — мини-плеер
```

Прокси защищён случайным ключом в каждой ссылке, поэтому другие программы и сайты не могут им пользоваться.

## Если что-то не играет

- **YouTube** иногда меняет API. Если треки YouTube перестали запускаться, положите `yt-dlp.exe` в любую папку из PATH — Nota сама переключится на него.
- **ВКонтакте**: если окно входа не закрылось само, нажмите ключик рядом с «Войти» и вставьте `access_token` вручную (Kate Mobile, client_id 2685278).
- **Яндекс Музыка**: без подписки Плюс API отдаёт только 30-секундные фрагменты или ничего.
- **SoundCloud**: треки Go+ помечаются «недоступен» (только превью).
- **Spotify-импорт** читает публичные плейлисты; закрытые не откроются.

## Важно

Nota работает через неофициальные API сервисов и ваши собственные аккаунты — так же, как Dotify. Сервисы могут менять API или ограничивать такие клиенты. Пользуйтесь своими аккаунтами и подписками.
